Smart Pantry Manager - A Java Android application that suggests recipes strictly based on leftover ingredients to cut food waste.

For this application I chose to use SQLite - SQLiteOpenHelper. It is a utility class in Android that simplifies the management of SQLite databases. 
SQLiteOpenHelper is designed to handle database creation and version management.
SQLiteOpenHelper simplifies many aspects of database management in Android and provides a structured way to interact with SQLite databases in applications.
It helps to avoid common pitfalls in database management and ensured that the database was properly created and upgraded as the app evolved.

Instructions for setup:
Clone this repository.
Open the project in Android Studio.
Run the app on an emulator or physical device (Minimum SDK: API 24).
The database and 18 seed recipes will be created automatically on the first run.
You can then add, edit or delete ingredients and view avalaiable recipes.
